How I work

The same three habits show up in every case study.

01

Start where it breaks

I look for the moment people give up or ask a colleague, then design around that moment.

02

Prototype the real flow

Clickable prototypes with real data, so reviewers test the decision, not the layout.

03

Leave a system behind

Components and rules developers can build from, so the next screen is faster.
