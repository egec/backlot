    00Overview

    Data health, product work at Insider One

    Telling marketers which data to trust before they build a segment

    Insider One is a customer data platform. Marketers build audiences from attributes and events that many sources send in. I designed three components, all shipped: a per-source breakdown on the attribute page, and a data health card in the segment builder for attributes and for event parameters.

    CompanyInsider One
    CategoryB2B SaaS, customer data platform

    01The problem

    The segment broke at the last step.

    The problem

    An attribute page showed one number, Total collected, with no way to see which source sent what. If an attribute’s data was wrong, the marketer found out only at the last step of building a segment, after setting up everything else.

    02Where data comes from

    Feature 01

    The total, split by where the data comes from

    Before, the attribute page showed one total. Now the total sits next to a count for every source, so a source that stops sending shows up here first.

    Before

    Only Total collected.

    After

    The total, then each group of sources with its own count.

    01

    Grouped by how data arrives

    SDK sources, external integrations and API sit in one group beside the total.

    02

    Every source named

    Mobile, Web, Shopify, Amplitude and API each show their own number.

    03

    Help next to the label

    Each label has a question mark that explains it on hover.

    03Data health in the menu

    Feature 02

    Data health shown inside the attribute menu

    The problem now shows while the marketer picks an attribute, not when the segment fails. Hovering an attribute opens a card with its sources, its volume and, if something is wrong, what and where.

    A healthy attribute

    An attribute with a problem

    01

    Healthy attributes stay quiet

    A blue top line, the sources that send it, how much came in and over what period.

    02

    A problem names its source

    Email Opt-in gets a warning icon in the list, a yellow top line and a red Email chip. The card says the data type is wrong.

    03

    Usable, with a way to fix it

    The attribute can still be used. Go to Data Validation opens the place to correct the data point.

    04Event parameters

    Feature 03

    The same check for event parameters

    A segment can also filter on what users did. Event parameters break the same way attributes do, so the parameter menu shows the same warning and the same card, worded for a parameter.

    One card, many cases

    Seven issue types: Incorrect Data Type, Invalid Value Format, Null Value, Missing Data, Abnormal Volume Change, Volume Threshold Reached, Multiple Issues.

    Five source states: Syncing, Not Used, Paused, Not Receiving Data, and no ingested data.
