Feature 06

Designed for the delivery that arrives broken

Automation sits in one step: after upload, the system reads technical metadata and assigns the files it can match. A wrong match is a mistake editors can't see, so the system suggests and the editor confirms.

  • Processing reads each file’s technical metadata and matches it to its content, so most files are assigned automatically. Only the ones it cannot place wait for the editor
  • One line reports the result: 24 uploaded, 9 assigned automatically, 15 need the editor
  • The drop zone stays, so files can be added mid-upload
  • Files keep their own states (Uploading, Processing, Ready, Needs assignment, Failed), separate from the workflow status of their content
Cuts the loop at Deliver→Prepare→Review→Release
