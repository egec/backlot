Feature 04

The editor never hunts for what is missing

It sits at the top. Everything the region still needs comes first, above what the upload already filled.

  • The readiness panel lists what must be complete before the season can be scheduled in this region
  • Checks show progress, not pass or fail: “4 of 8” tells the editor how much work is left and where to start, “incomplete” only says something is wrong
  • Every empty field is grouped in “Needs your input”, above what the upload already filled
  • Values read from the media file, like runtime and codec, can never be edited, because they describe the file itself. Values from the delivery unlock one field at a time, so every change is deliberate
  • Submit for review hands the episode to the publisher. Save keeps unfinished work without submitting it, so the episode stays under In progress on the dashboard, easy to pick up later
Cuts the loop at Deliver→Prepare→Review→Release
