Feature 08

Artwork is chosen by taste, not by country

Most viewing starts from a recommendation, so the thumbnail does much of the selling. Taste predicts a click better than age or location, so each season carries one thumbnail per taste cluster.

  • One thumbnail per taste cluster: action, drama, romance and mystery fans each see the scene that speaks to them
  • Variants are tested against each other in each region, with the time left on the test, so the editor knows when the artwork is final
  • Each variant shows its click-through rate, and the leader is marked, so the choice is backed by data, not taste
Cuts the loop at Deliver→Prepare→Review→Release
